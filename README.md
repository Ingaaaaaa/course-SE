# 论文智能排版 AI Agent

> 
> 课程大作业｜Python 项目

## 📖 项目简介

本项目是面向学术论文的智能排版 AI Agent，辅助完成论文文本处理、格式规范化、内容整理工作，减少人工调整论文格式的重复工作量。项目基于 Python 开发，实现 Agent 任务拆解、文本解析、格式校验、内容优化等核心能力。

## 🛠️ 技术栈

- 开发语言：Python 3.10+
- GUI 框架：Tkinter
- 核心依赖：大模型 API、python‑docx
- 数据库：SQLite

## ✨ 功能特性

- ✅ Word 文档读取与文本清洗
- ✅ AI 分层语义识别，自动识别标题、摘要、正文、参考文献
- ✅ 自定义排版参数（字体、字号、行距、缩进）
- ✅ 一键全自动完整排版流程
- ✅ 排版结果导出 Word 文档
- ✅ 学术错误检测与 AI 一键纠错
- ✅ 排版模板保存、导入导出
- ✅ 任务、错误记录持久化存储

## 🏗️ 系统架构

> <img width="866" height="816" alt="image" src="https://github.com/user-attachments/assets/e34a3d10-2592-4309-ab0b-1ba0b0e4f64f" />

> 图 5‑1 论文智能排版 AI Agent 分层架构图

系统四层分层架构如上图所示，自上而下依次为**主界面层、业务模块层、配置层、外部依赖层**，层级遵循单向依赖规则，上下层职责完全解耦。

1. **主界面层**：Tkinter GUI 图形界面，接收用户交互操作
2. **业务模块层**
   - A 模块 `ui_doc_handler`：文档读取与文本清洗
   - B 模块 `ai_processor`：AI 大模型语义分层解析
   - C 模块 `formatter_exporter`：格式化渲染与文档导出
3. **配置层**：全局配置 Config、API 密钥、默认排版参数，消除硬编码
4. **外部依赖层**：第三方大模型 API，提供 AI 文本识别能力

分层解耦，便于单元测试与后续扩展新功能，新增校对、多格式导出等功能，无需改动整体架构。

## 🗄️ 数据模型

> <img width="865" height="628" alt="image" src="https://github.com/user-attachments/assets/88432d2b-b693-483f-9f69-23c81de289dd" />

> 图 6‑1 系统数据库 ER 图

数据库包含五张核心数据表：`PaperTask`、`Template`、`Segment`、`ErrorRecord`、`FixRecord`。

- `Template` 和 `PaperTask`：一对多，一套排版模板可以被多个排版任务使用
- `PaperTask` 和 `Segment`：一对多，一篇论文任务包含多个文本片段
- `Segment` 和 `ErrorRecord`：一对多，一个段落可以检测出多条学术错误
- `ErrorRecord` 和 `FixRecord`：一对一，一条错误对应一条修正记录

所有一对多关系通过`task_id`外键完成绑定；为`task_id`建立索引，提升任务数据查询速度。

> 
> AI 解析过程内存中使用`struct_data` JSON 结构体，和数据库持久化实体一一对应。

## 💻 系统实现

> <img width="865" height="538" alt="image" src="https://github.com/user-attachments/assets/1abb67bc-7423-4c4c-9d53-6b53773b9f83" />

> 图 7‑1 论文智能排版系统主操作界面

图形界面划分为三大区域：

1. **模板管理区**：排版模板新增、保存、导入导出；解析外部格式规范文档
2. **AI 学术纠错分析区**：错误检测层级选择，一键学术纠错、全文修正
3. **排版参数设置区**：设置正文字体、标题字号、行距、首行缩进，支持恢复默认参数

底部状态栏实时展示 AI 任务进度与错误记录。用户界面操作会调度底层 A/B/C 业务模块，任务、段落、错误、模板信息持久化存入数据库。

## 📝 项目总结

### 难点与实现

1. 论文非标准化文本的解析、分段处理
2. AI Agent 任务调度，把复杂排版拆分成多个子任务
3. 排版规则与论文结构化数据的匹配映射

### 不足与展望

- 当前主要面向 docx 文档，后续可以拓展 LaTeX、PDF 完整导出能力；
- 优化大模型提示词，进一步提升格式识别、学术纠错准确率。
